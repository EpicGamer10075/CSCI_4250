To run a .lua file, you will need Love, which can be downloaded here:
  https://love2d.org
This will install Love on your computer, and you should keep track of where that is.
When you want to run a script in lua, you will need a folder containing the lua files,
  with one of them being called "main.lua"
This file will be the one that starts execution, with all others being used by it
To actually run the file, you will need to execute the command:
  "[Folder containing Love]\love 11.5\lovec.exe" "[Location of Test folder]\Test"
This executes the Test folder with lovec.exe, and will run the code in main.lua in Love
