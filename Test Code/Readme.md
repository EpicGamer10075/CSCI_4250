<p>To run a .lua file, you will need Love, which can be downloaded here:</br>
  https://love2d.org</br></br>
This will install Love on your computer, and you should keep track of where that is.</br></br>
When you want to run a script in lua, you will need a folder containing the lua files,</br>
  with one of them being called "main.lua"</br>
This file will be the one that starts execution, with all others being used by it</br></br>
To actually run the file, you will need to execute the command:</br>
  "[Folder containing Love]\love 11.5\lovec.exe" "[Location of Test folder]\Test"</br></br>
This executes the Test folder with lovec.exe, and will run the code in main.lua in Love</p>
